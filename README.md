One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline.

`main.py` (stdlib only) copies `entry.txt` byte-identical to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), mode 0644, with a single direct write and no temporary file.
